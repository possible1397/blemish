# 瑕疵檢測程式

這是一個使用 OpenCV 撰寫的影像瑕疵檢測工具，能夠批次處理圖片並標示出可能的黑點或缺陷。

## 功能特色

- 支援批次處理資料夾內的圖片
- 透過灰階、中值濾波、CLAHE、二值化與形態學處理進行檢測
- 將偵測結果以紅框標示並儲存至指定資料夾
- 可開啟 debug 模式顯示處理過程

## 執行方式

1. 安裝套件：
```bash
pip install opencv-python numpy
```

2. 執行：

```bash
python blemish.py
```

---

## 處理流程

```
灰階  →  中值濾波 (k=7)  →  CLAHE (clip 0.5, tile 50×50)
     →  Otsu 二值化 (閾值 −5 偏移，反二值化)
     →  開運算 ×2  →  閉運算 ×2  (5×5 kernel)
     →  輪廓擷取  →  面積篩選 (800 – 50000 px)  →  紅框標示
```

CLAHE 的 `tileGridSize` 刻意設得大（50×50）而 `clipLimit` 設得小（0.5），目的是在不放大雜訊的前提下壓抑背景照度不均。二值化在 Otsu 自動閾值上再減 5，是為了讓判定稍微保守一點、減少把背景紋理誤判成缺陷。

## 目前狀態

**已驗證**
- 批次讀取資料夾影像、輸出紅框標示結果
- 對「暗於背景」的點狀缺陷，在測試影像上可穩定框出
- debug 模式可逐步檢視灰階、CLAHE、二值化、形態學各階段結果

**已知限制**
- **參數全部寫死在程式內**：濾波核、CLAHE 參數、Otsu 偏移量、面積上下限都是針對當時那批影像調出來的，換一組光源或鏡頭就要重調。
- **只判斷亮度方向為「暗」的缺陷**：使用 `THRESH_BINARY_INV`，亮於背景的缺陷（如亮點、反光）不會被偵測。
- **只用面積篩選**：沒有長寬比、圓形度等形狀特徵，因此刮痕與點狀缺陷無法區分，細長刮痕也容易因為面積不足被濾掉。
- **Otsu 是全域閾值**：CLAHE 能緩解照度不均，但無法根治。大面積漸層背景仍可能讓閾值偏移。
- **沒有量化評估**：沒有標註資料集，所以說不出召回率與誤報率，目前只能靠肉眼確認。
- 量測單位是像素，未做相機標定，無法換算成實際物理尺寸。

**下一步**
1. 參數外部化成設定檔，讓不同產品／光源條件可以各自保存一組配方。
2. 建立小型標註資料集（數十張即可），把「看起來有抓到」變成可量化的召回率與誤報率——這是最優先的，沒有這個就無法判斷後續任何改動是進步還是退步。
3. 加入形狀特徵（長寬比、圓形度、填充率）做缺陷分類，區分點、線、面三類。
4. 支援雙向閾值，同時偵測亮缺陷與暗缺陷。
5. 改用區域自適應閾值（如 `adaptiveThreshold`），降低對背景均勻度的依賴。
